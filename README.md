# Tic Tac Toe Game

A simple, interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay (Player X vs Player O)
- Real-time game status updates
- Win detection for all possible combinations
- Draw detection when the board is full
- Reset button to start a new game
- Responsive and visually appealing design
- Hover effects and smooth transitions

## How to Play

1. Open `index.html` in your web browser
2. Player X starts first by clicking any empty cell
3. Players take turns clicking cells to place their marks
4. The game ends when:
   - A player gets three in a row (horizontally, vertically, or diagonally) - that player wins
   - All cells are filled with no winner - the game is a draw
5. Click "Reset Game" to start a new game

## Game Rules

- Players alternate turns placing X and O
- The first player to get three of their marks in a row wins
- If all 9 cells are filled with no winner, the game is a draw
- Cells cannot be reused once played

## Files

- `index.html` - Game structure and layout
- `styles.css` - Game styling and animations
- `script.js` - Game logic and event handling

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Gradients)
- Vanilla JavaScript (ES6)
